## Цель

Пользователь может выбрать блюда на завтрак, обед и ужин и видеть суммарные калории.

## Нужно реализовать

- Модель DailyMeal
- Модель DailyMealItem
- Создание записи на текущий день
- Выбор рецепта для breakfast / lunch / dinner
- Отображение выбранных блюд на dashboard
- Подсчёт суммарных калорий и прогресс-бар

## Критерий готовности

## Пользователь выбирает блюда на день, видит итоговые калории и прогресс (например 1200 / 2100).

Всё делается на той же странице dashboard

1. Создать модель DailyMeal (запись на день, привязана к пользователю и дате) ✅

- Работаю пока только с сегодняшней датой

1. Создать модель DailyMealItem (конкретное блюдо: тип приёма пищи + рецепт) ✅

2. Создать API: GET /api/daily-meal — создать/получить запись на сегодня ✅

3. Создать API: POST /api/daily-meal/item — добавить блюдо в приём пищи ✅

4. Создать API: DELETE /api/daily-meal/item/:id — удалить блюдо ✅

5. На dashboard добавить секции с колонками: Завтрак - Обед - Ужин - Перекус/другое - Итого за день ✅

6. В каждой колонке — кнопка добавить блюдо и модальное окно ✅

7. Нужно разобраться с подсчётом калорий каждого блюда ✅

8. Подсчитать суммарные калории и показать прогресс относительно dailyCalories из профиля (тут надо расширить GET запрос daily-meal) ✅

9. Внедрить state manager (Zustand, Redux Toolkit, TanStack Query) и отрефакторить все запросы. ✅

10. Проверка в POST /api/daily-meal/item добавить проверку, что dailyMealId принадлежит текущему пользователю, перед create.
