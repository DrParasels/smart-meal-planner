## Цель

На странице `/shopping-list` показать агрегированный список ингредиентов из выбранных блюд на сегодня:

- без дублей (одинаковые ингредиенты объединяются),
- с возможностью отмечать купленные позиции,
- с верхней кнопкой "Перейти к плану питания" (возврат на `/dashboard`).

## Нужно реализовать

- Источник данных: блюда пользователя из `DailyMeal` за текущий день.✅
- Агрегация ингредиентов из выбранных рецептов:
  - группировка по `ingredientId` (или нормализованному названию),✅
  - суммирование массы (`mass`) по всем рецептам.✅
- Отдельная страница `/shopping-list`. ✅
- Список ингредиентов: ✅
  - чекбокс "куплено / не куплено",
  - название,
  - итоговая масса,
  - сортировка А-Я.
- Верхняя секция: ✅
  - заголовок "Список покупок",
  - подзаголовок "Ингредиенты, необходимые для приготовления запланированных блюд на сегодня",
  - кнопка "Перейти к плану питания".
- Блок "Сводка" (без пункта "Блюд на сегодня"): ✅
  - количество ингредиентов,
  - калории,
  - прогресс купленных позиций (progress bar).

## API / данные

1. Создать модель `ShoppingList` (заголовок списка на день, привязка к пользователю и дате). ✅
2. Создать модель `ShoppingListItem`:

- `shoppingListId`,
- `ingredientId` (или snapshot названия),
- `totalMass`,
- `isChecked`. ✅

3. Реализовать API:

- `POST /api/shopping-list` — сформировать список из `DailyMeal` за сегодня (с агрегацией), ✅
- `GET /api/shopping-list` — получить список пользователя за сегодня,✅
- `PATCH /api/shopping-list/item/:id` — изменить `isChecked`.✅

## Критерий готовности

Пользователь на dashboard нажимает "Сформировать список покупок", переходит на `/shopping-list` и видит:

- объединённый список продуктов без повторов,
- чекбоксы с сохранением состояния,
- корректную сводку (ингредиенты, калории, прогресс),
- кнопку "Перейти к плану питания" в верхней части страницы.

1. Создать модель ShoppingList POST/GET/PATCH - сформировать/получить/меняется при изменении чекбокса

3. Создать верхнюю секцию - "Список покупок", "Ингредиенты, необходимые для приготовления запланированных блюд на сегодня", кнопка "Перейти к плану питания" (возврат на dashboard);
